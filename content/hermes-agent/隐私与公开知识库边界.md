# Hermes Agent 隐私与公开知识库边界

知识库网站是公开站点。因此，所有进入其中的内容都必须假设会被搜索引擎、陌生访客和 Git 历史永久看到。

## 可以记录

- 通用的工具使用方法和公开文档链接；
- 不含个人标识的操作流程、故障排查经验和设计决策；
- 已公开发布的软件项目、标准命令和通用配置示例；
- 经过脱敏的目录结构、接口说明和恢复步骤；
- Hermes 的公开协作约定和概念说明。

## 不得记录

- 密码、API Key、Token、私钥、Cookie、OAuth 凭据和完整环境变量；
- 邮箱地址、电话号码、住址、内部域名、内部 IP、设备序列号等个人或基础设施标识；
- 私人聊天内容、会话原文、个人日程、财务或工作隐私；
- 未公开仓库的源码、内部链接、专有模型名称或 NDA 约束的信息；
- 可以拼接出账号权限、网络拓扑或真实身份的组合信息。

## 脱敏方法

- 用 `<示例路径>`、`<用户名>`、`<服务地址>`、`<变量名>` 等占位符替代真实值；
- 只保留解释方法所必需的最少信息；
- 示例凭据必须使用明显无效的占位文本，不能使用真实格式的复制品；
- 发布前检查 Markdown、代码块、Git diff 和提交内容；
- 如果无法确定某项信息是否安全，默认不发布，先询问用户。

## 三者的分工

| 位置 | 用途 | 是否公开 |
|---|---|---|
| Hermes 持久记忆 | 少量长期偏好和边界 | 不直接发布 |
| Hermes 技能 | 可复用的工作流程 | 通常不公开，除非已脱敏并明确适合分享 |
| 公开知识库 | 完整、可阅读、可检索的脱敏资料 | 是 |

这条边界优先于“记录完整”的要求：宁可少记录，也不能把私人信息推到公开站点。
