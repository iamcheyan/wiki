# Hermes Agent

Hermes Agent 是一个可以通过终端、桌面应用、网页界面和消息平台使用的 AI Agent。它不仅能回答问题，也能读取和修改文件、运行命令、检索资料、执行自动化任务，并把可复用的工作流程保存为技能。

本目录只记录**可公开分享的知识**，不记录账号、密钥、个人地址、聊天内容或机器专属敏感信息。
